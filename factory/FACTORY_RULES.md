# FACTORY_RULES.md — operating procedure

1. Intake: PRD → gate questions (scope? tests? what does done look like?)
2. Plan: smallest diff that ships value; split into rounds
3. Build: one round at a time; messy start is fine, motion matters
4. Validate: run tests, verify on disk
5. Review: fresh-context agent reviews before merge
6. Merge only when validated; log outcome to orchestration/outcomes.jsonl
