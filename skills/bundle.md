# Coden607 Runtime Skill Router

## SKILL: canonical-skill-router

**Use when:** every request handled in a project or agent configured to use the Coden607 skills library.

### Procedure

1. Treat https://github.com/coden607/skills as the canonical library.
2. Refresh or inspect the canonical top-level */SKILL.md catalog before selecting a skill when live GitHub access is available.
3. Narrow candidates from the task, then inspect their frontmatter description / use-when text. Load only the smallest relevant set, normally 1–3 skills.
4. Read each matched SKILL.md enough to follow its procedure. Load referenced support files only when required.
5. Never preload or execute the entire catalog merely because it is installed.
6. If live GitHub access is unavailable, use coden607-skills-bundle.md generated by scripts/build-runtime-bundles.py.
7. Runtime adapters may change discovery paths, but must not change canonical skill intent.
8. Installing or matching a skill does not authorize destructive actions, outbound messages, production deployment, billing, secret rotation, or other gated actions.

### Runtime paths

- Claude Code: ~/.claude/skills
- Codex CLI: ~/.codex/skills
- Grok Build: ~/.grok/skills plus ~/.grok/AGENTS.md
- Gemini CLI: ~/.gemini/GEMINI.md, canonical skills at ~/.coden607/skills
- Kimi Code: ~/.kimi-code/AGENTS.md and ~/.agents/AGENTS.md, canonical skills at ~/.coden607/skills
- ChatGPT Projects / GPT Knowledge: use this router plus the generated coden607-skills-bundle.md when live GitHub retrieval is unavailable.
